Seerr requests (optional)

Seerr is the merged Overseerr and Jellyseerr. The address this server reaches it at. Save key and Test Seerr save it too. Moving it to another server removes the saved key, so paste the key again with the new address.
If people open Seerr at a different address than this server uses (http://seerr:5055 inside Docker, say), put theirs here. Links to Seerr use it.
Checking…
With a key saved, the Request button sends the request to Seerr as the person who pressed it, using their own Seerr account, so their permissions, request limits and auto-approval all apply. Each person needs to have signed in to Seerr once with their Jellyfin login. Without a key, the button opens the title in Seerr instead.
A My requests section on the My picks page: waiting for approval, looking for a download, downloading (with progress and when it should be ready), or ready to watch. Progress comes from Sonarr and Radarr through Seerr, so they need to be set up in Seerr. Each person only sees their own. Admins also see everyone's requests waiting for approval there, with Approve and Decline.

Who gets Discover picks

Untick children's accounts. Discover titles come from TMDb, so your parental controls can't filter them: accounts with parental controls (a maximum rating, or blocked or allowed tags) start unticked, and only get Discover if you tick them. Picks from your own library always follow each user's parental controls.
