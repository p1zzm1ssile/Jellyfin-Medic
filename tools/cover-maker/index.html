Library Cover Maker

Add up to 5 videos or pictures, type your library name, and get an animated WebP cover that cuts between random moments from each one. Pictures get a slow zoom. Every click picks new random moments.

Drag to move the picture. Scroll or use the Zoom slider to resize it. Click a file in the list to preview it.

6 s

  1. Click Download animated cover (or right-click the animation → Save image as…).
  2. In Jellyfin, right-click the library → Edit images → upload it with type Logo.
  3. Add the CSS from the chat for that library, then press Ctrl+F5.
