            What's in your IPTV libraries

            Counts your IPTV films and series by genre and country, shows how much of each gets watched, and finds live channels that appear several times in different qualities. It reads a lot, so it only runs when you ask. Run it when nobody's watching.

            This is the one tool that changes your actual media files. It removes audio and subtitle tracks by remuxing (no quality loss), but back up and run it on a few files first. It skips IPTV, never removes the last audio or subtitle track, always keeps forced subtitles, and by default moves each original into a hidden .medic-originals folder next to it, so your library still has one file per title.

            Remove unwanted tracks

            Keeps your languages plus the native track where it's the only one (so anime and foreign films stay watchable). Set the languages and options in Track settings above.

            Remove duplicate files

            Medic 1.0.4 to 1.0.7 left a stripped copy beside each original (for example "Film.medic-stripped.mkv"), and could strip that copy again. This puts each title back to a single file under its original name and deletes the copies of copies. A copy FFprobe doesn't read like the film (missing its video or audio, or shorter) is left where it is, and so is the film. The original is kept in a hidden .medic-originals folder unless you tick the box below.

            Before converting anything

            • These are estimates. Real savings depend on the source and the quality you choose.
            • GPU encoders are fast but make bigger files than slow software encoding at the same quality, so both figures are shown.
            • Keep the same file name and file type when converting, so Jellyfin keeps the item, its artwork and watched status.
            • If Sonarr or Radarr manage these files, check their quality profiles first. If they score HEVC or x265 differently, converted files can trigger re-downloads.
            • Re-encoding always loses a little quality. Many people leave 4K and remux files alone.
            • Medic doesn't convert anything. Tools like Tdarr or Unmanic can, using these numbers as a guide, and Medic's Tracks tab can remove unwanted audio and subtitle tracks without re-encoding.

            These tests use your GPU, CPU and internet connection for a minute or two. Run them when nobody's watching.

            Playback test

            Plays two of your films through Jellyfin's transcoder for up to a minute each, exactly as an app would, then checks how fast it ran and whether your GPU did the decoding, encoding and HDR tone mapping.

            Image extraction test (trickplay and chapter images)

            Scans the first 20 minutes of a film the way trickplay and chapter images do, once on your GPU and once on the CPU, and times both. Nothing is saved.

            Internet speed test

            Measures your server's own connection, not this device's, because that's what people watching away from home depend on. Uses Cloudflare's public speed-test service, takes about 20 seconds, and uses up to a few hundred MB on a fast connection.

            Help improve Jellyfin Medic (optional)

            Medic's advice is only as good as the plugins it knows about, and no one person can install every Jellyfin plugin to learn them all. If you'd like to help, you can send your plugin settings so support for the plugins you use can be improved.

            Before anything leaves your server, Medic replaces the personal data it can identify — passwords, API keys, tokens, usernames and any credentials inside web addresses — with ****. This masking covers the common cases but can't be guaranteed to catch everything, so it's your responsibility to read the file before you send it.

            Personal data isn't wanted. If any does reach the maintainer, it's removed and not used, as a matter of integrity. Nothing is sent automatically; emailing the file is your choice. If you do, email it to p1zzm1ssilerepo@gmail.com, where it's used only to improve the plugin and deleted once that's done.

            Read through before sharing, in case anything private slipped through.
