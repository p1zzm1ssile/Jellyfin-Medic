        What's in your IPTV libraries

        Counts your IPTV films and series by genre and country, shows how much of each gets watched, and finds live channels that appear several times in different qualities. It reads a lot, so it only runs when you ask. Run it when nobody's watching.

        These tests use your GPU, CPU and internet connection for a minute or two. Run them when nobody's watching.

        Playback test

        Plays two of your films through Jellyfin's transcoder for up to a minute each, exactly as an app would, then checks how fast it ran and whether your GPU did the decoding, encoding and HDR tone mapping.

        Image extraction test (trickplay and chapter images)

        Scans the first 20 minutes of a film the way trickplay and chapter images do, once on your GPU and once on the CPU, and times both. Nothing is saved.

        Internet speed test

        Measures your server's own connection, not this device's, because that's what people watching away from home depend on. Uses Cloudflare's public speed-test service, takes about 20 seconds, and uses up to a few hundred MB on a fast connection.

        Help improve Jellyfin Medic (optional)

        Medic's advice is only as good as the plugins it knows about, and no one person can install every Jellyfin plugin to learn them all. If you'd like to help, you can send your plugin settings so support for the plugins you use can be improved.

        Before anything leaves your server, Medic replaces the personal data it can identify — passwords, API keys, tokens, usernames and any credentials inside web addresses — with ****. This masking covers the common cases but can't be guaranteed to catch everything, so it's your responsibility to read the file before you send it.

        Personal data isn't wanted. If any does reach the maintainer, it's removed and not used, as a matter of integrity. Nothing is sent automatically; emailing the file is your choice. If you do, email it to jellyfinmedic@anglernook.com, where it's used only to improve the plugin and deleted once that's done.

        Read through before sharing, in case anything private slipped through.
